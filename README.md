# AI-Web-Translation-Assistant

一个合并版的 Tampermonkey 用户脚本：**F9 一键翻译当前网页**，同时包含「GitHub 汉化」与「超级翻译助手」两套能力。

## 功能

- **整页翻译**：按 **F9** 翻译当前页。GitHub / gist 走词库汉化 + AI 大模型补译（词库没命中的英文交给大模型，失败再回退引擎链）；其它站点走 Bing → MyMemory → Google 引擎链整页机翻。
- **GitHub 汉化**：内联 1689 条词库 + CSS 规则，覆盖导航、按钮、属性、相对时间、占位符等，自动排除代码块、文件名、路径。
- **翻译引擎链**：Bing 鉴权失败自动刷新重试，上次成功的引擎优先，长文本自动分段。
- **AI 大模型补译**：词库没命中的英文短文案交给你配置的大模型批量翻译，译文写入缓存，二次访问零请求。
- **译文缓存**：AI 结果写入本机存储，避免重复请求。

## 触发方式

- 翻译**仅由 F9 触发**：页面加载后脚本不做任何自动改写，按 F9 才执行。
- 焦点在输入框或可编辑区时按 F9 不触发，避免打断打字。
- 连按 / 长按 F9 只执行一次，不重复翻译。

## AI 大模型设置

打开设置入口（二选一）：
- 篡改猴菜单里的 **「AI 翻译设置」**
- 页面左下角的 **「⚙ AI 设置」** 浮动按钮

面板里可填：

| 字段 | 说明 |
| --- | --- |
| 启用 AI 补译 | 开关；关闭则 GitHub 只走词库 + 引擎兜底 |
| 接口类型 provider | `nvidia` / `openai` / `builtin`（浏览器内置 AI，免 Key） |
| 接口地址 baseUrl | OpenAI 兼容的 `/chat/completions` 地址 |
| API Key | 大模型 Key，仅保存在本机 |
| 模型名称 model | 例如 `nvidia/nemotron-3.5-super-vl-120b-a12b` |
| 批量条数 | 每次请求翻译多少条 |
| 每条最长字符 | 超过长度不交给 AI |
| 超时 | 请求超时毫秒 |
| 推理模型关闭思考 | NVIDIA Nemotron 系列需要 |
| 译文写入缓存 | 关闭则不缓存 |

填完点 **保存**；点 **测试连接** 会用当前值发一次真实请求验证可用性。配置存本机篡改猴存储，重启浏览器后仍在。

> 公开版本内置的 NVIDIA API Key 已置空，使用前请在设置里填入你自己的 Key；或 provider 选 `builtin` 用浏览器内置 AI（免 Key）。

## 安装

1. 浏览器装好 Tampermonkey（篡改猴）。
2. 把 `AI-Web-Translation-Assistant.user.js` 拖入浏览器安装；或在篡改猴「新建脚本」里粘贴代码。
3. 打开任意网页，按 F9 翻译；GitHub 页面先在设置里填好 AI Key。
