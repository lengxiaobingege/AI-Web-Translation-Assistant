维护者操作手册。审查依据：[脚本站审核规则 V0.3](https://bbs.tampermonkey.net.cn/thread-3036-1-1.html)（2022-09-09 发布，2025 年论坛新人手册仍将其列为现行规则）。

站点入口：<https://scriptcat.org/search>。论坛侧若要发帖，需**先**在脚本站发布，再到「油猴脚本」板块绑定。

| 项 | 当前状态 | 说明 |
| --- | --- | --- |

## 二、表单怎么填

**发布入口**：登录 `scriptcat.org` 后从站内导航进「发布脚本」。网上老教程里的 `/zh-CN/post-script` 直链已失效（实测 404），不要照抄。

**代码**：脚本约 220 KB，优先**整份粘贴** `AI-Web-Translation-Assistant.user.js`，最稳且能保证市场里的版本就是你推的那版。若表单提供「上传文件」或「从 URL 导入」再用它们。

### raw 地址怎么填

「脚本地址 / 自动同步」这一栏是**脚本猫服务器**去拉文件，用户浏览器不直接接触。三条候选：

```text
# A 官方直链（本机实测超时，但脚本猫服务器可能可出墙）
https://raw.githubusercontent.com/lengxiaobingege/AI-Web-Translation-Assistant/main/AI-Web-Translation-Assistant.user.js

# B jsDelivr（实测 200，有几小时缓存延迟）
https://cdn.jsdelivr.net/gh/lengxiaobingege/AI-Web-Translation-Assistant@main/AI-Web-Translation-Assistant.user.js

# C gh-proxy 反代（实测 200，实时无缓存）
https://gh-proxy.com/https://raw.githubusercontent.com/lengxiaobingege/AI-Web-Translation-Assistant/main/AI-Web-Translation-Assistant.user.js
```

| 字段作用 | 填哪条 | 原因 |
| --- | --- | --- |
| 一次性导入代码 | B 或 C | 拉得到即可 |
| 长期自动同步 | C | 实时；B 的缓存会让发版后市场仍读旧版 |
| 想用官方源 | A | 仅当脚本猫服务器能访问 GitHub 时才有效 |

**不要填** `github.com/.../blob/main/...user.js`（那是 HTML 网页）或仓库主页。填完点导入，确认解析出的名称是「AI 网页翻译助手」、版本与当前 `@version` 一致。

其余字段：**主页 / 源码**填仓库地址；**分类**选翻译或效率工具；**标签**填翻译、AI、效率工具；**许可**留空。

### `@updateURL` 别急着改

脚本头这两行由**用户浏览器里的脚本管理器**请求，和上面的表单不是一回事：

```js
// @downloadURL https://raw.githubusercontent.com/.../AI-Web-Translation-Assistant.user.js
// @updateURL   https://raw.githubusercontent.com/.../AI-Web-Translation-Assistant.user.js
```

发布后从市场装一次，实测「检查更新」走哪个地址：走 `scriptcat.org` 则什么都不用动；仍走 raw 才把这两行改成市场给的更新地址再发一版。**不要改成 B/C**——那会让所有非脚本猫用户也跟着走 CDN 缓存或第三方代理。ScriptCat 官方元数据文档另有一条约束：配了 `@updateURL` 就必须同时配 `@downloadURL` 才生效，本项目两条齐全。

## 三、审查规则对照

| 规则 | 结论 | 依据 |
| --- | --- | --- |
| 1 禁止引入私有外部执行代码 | 通过 | 远端只拉词库 JSON，全部 `JSON.parse`；`innerHTML` 仅 4 处，均为本地拼的面板 HTML，外部值经 `esc()` 转义。词库里的 24 条正则与 1 条 HTML 替换规则是纯数据，替换值为中文「拉取请求」，不含脚本 |
| 2 引用他人代码须遵守原协议并声明来源 | 需说明 | 两个上游均无 LICENSE；头部注释、README「来源」「许可」已写明归属与「不代授权」。规则对「未声明 @license 的脚本」不主动处理，但原作者举报即处理，属长期风险 |
| 3 二创须有实质改进 | 通过 | 三层调度、全站词条、三态存储、镜像降级、词条回传均为实质新增 |
| 4 以引用时 license 判断 | 已核实 | `k1995/github-i18n-plugin`、`syhyz1990/translate` 的 GitHub `license` 字段均为 `None` |
| 5 禁止加密混淆 | 通过 | 全明文 |
| 6 禁止无意义脚本 / 广告 | 通过 | 功能完整，无推广 |
| 7 `@antifeature` | 无需标注 | 六类不受欢迎功能均不涉及 |
| 8 禁止成人内容 | 通过 | — |
| 开头：填好元数据、善用标签 | 通过 | `@name`/`@description`/`@tag` 齐全 |

**主动写进介绍正文的两点**（不算违规，但不写容易被追问）：默认自动翻译会把页面文本发给翻译服务；`@icon` 的大段 base64 是内嵌 PNG 而非混淆。

## 四、可直接复制的介绍正文

```markdown
# AI 网页翻译助手

任何网页，只要不是简体中文就自动翻成中文；F9 随时重译。只提供用户脚本这一种形态，装一个脚本管理器（篡改猴、脚本猫、暴力猴等）即可。

## 三层路径

本地界面词条 → AI 大模型 → 免费引擎链。前一层能解决就不花后一层的钱。

- **界面词条**：所有网站共用同一套词库，命中直接替换，零网络、零额度；自动排除代码块、文件名、路径。
- **AI 翻译**：按批交给你在设置里配置的大模型，译文缓存复用；不填 Key 也能用 `builtin`。
- **免费引擎链**：Bing → MyMemory → Google，AI 不可用、失败或文本超长时才兜底。

按 F9 翻译；页面已翻译时再按 F9 会先恢复原文再重译。打开设置面板：`Alt+N`，或在脚本管理器的菜单里点「AI 翻译设置」。

## 数据与隐私

- 自动翻译默认开启，会把当前页面的可见文本发送给你选定的 AI 服务商，或 AI 不可用时发往 Bing / MyMemory / Google。这是整页翻译的实现方式，不收集用户身份、Cookie 或浏览历史。
- API Key 只保存在本机脚本管理器存储里，不写入任何远端；公开版内置 Key 为空。
- 词库同步是只读 GET，不上传任何内容；词条回传默认关闭，必须手动点按钮。
- 不介意的话可直接使用；介意页面内容离开本机，请在设置里关掉「非简体中文页面自动翻译」，或不要安装。

## 词库

正式词库托管在仓库 `dict/zh-CN.json`，每天 0 点后首次访问自动同步，GitHub 原始地址与镜像并发、失败自动降级；离线时继续用本机缓存。所有网站共用这一份，不按站点区分。

## 来源与许可

本脚本基于两个独立项目合并改编，二创新增内容包括三层调度、AI 批量翻译与缓存、词条库维护流程、设置面板、跨管理器适配：

- `k1995/github-i18n-plugin` —— 界面词条与替换规则
- `syhyz1990/translate` —— 整页翻译引擎链

两个上游仓库均未声明开源许可（无 LICENSE 文件），权益归各自原作者所有。本脚本**不附带任何许可声明，也不代上游授权**；如原作者有异议会立即移除对应部分。图标为本项目自绘的原创几何图形，以 data URI 内嵌（脚本体积里那段 base64 就是它，不是加密或混淆），不含第三方商标或字体。

源码、完整文档与反馈：https://github.com/lengxiaobingege/AI-Web-Translation-Assistant
```

## 五、发布后

1. 拿到 `scriptcat.org/zh-CN/script-show-page/<编号>` 后，回填 README 安装章节作为国内用户的首个地址。
2. 从市场装一次，看管理面板「检查更新」实际请求的地址（见上）。
3. 之后每次发版：递增 `@version` → 推 GitHub → 到「我的脚本」更新代码；若表单支持自动同步，填上面 C 那条地址。

## 六、尚未核实的点

- 新版发布表单的确切字段与是否支持 URL 导入：站点对未登录访问不返回表单，旧路径已 404，以登录后实际页面为准。
- 脚本市场是否接管 `@updateURL`：需发布后实测，不要提前改脚本头。
- 规则帖标题为「初版」，发布前可再看一眼站内是否有更新公告；2025 年论坛指引仍链接此帖。
